STEP 2 — HOST THE PRIVACY POLICY (do this before other forms)
================================================================

Play rejects apps with a missing or 404 privacy URL.

1. Open privacy-policy.html in this project.
2. Replace the contact sentence with your real email.
3. Put the file on a public HTTPS page. Easiest options:
   - GitHub Pages: create a public repo, put privacy-policy.html in it,
     enable Pages, URL looks like https://YOURUSER.github.io/REPO/privacy-policy.html
   - Any site you already own.
4. Open the URL in an incognito window. It must load with no login.

You need this URL for Store settings AND Data safety. Keep it handy.

STEP 8 — CLOSED TESTING  (needed for new personal accounts)
================================================================

If your Play developer account is a PERSONAL account created after
13 November 2023, Production stays locked until you finish this.

Path: Test and release → Testing → Closed testing
  Create track if asked (default "Closed testing" is fine)
  Create new release → use the same 1.0.0 AAB (or Promote from internal)
  Release notes: same as Step 7
  Roll out to Closed testing

Testers
  Testers tab → Create email list
  Add at least 12 Gmail addresses of real people
  Each person must:
    1. Open the opt-in link
    2. Accept to become a tester
    3. Install the app from the Play Store testing page

Rules Google actually checks
  - 12 testers opted in
  - Continuously opted in for the last 14 days
  - Adding emails without them opting in does NOT count

Share the opt-in link with friends. Ask them to leave the app installed
for 2 weeks and not leave the test.

Wait 14 days. Watch the Dashboard progress toward production access.
